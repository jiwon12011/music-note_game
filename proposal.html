02

Application Need

실제 사이트 활용 필요성

왜 이 웹페이지를 실제 사이트로 사용해야 하는가

비주얼노벨 장르는 사용자가 플레이 전 접하는 첫 화면의 인상이 중요합니다.

현재 완성된 웹페이지는 LP, 캐릭터, 스틸컷, 감성 컬러를 통해 게임의 핵심 분위기를 빠르게 전달할 수 있습니다.

따라서 이 페이지를 실제 홍보 사이트로 사용하면, 사용자는 다운로드 전 게임의 장르와 매력을 먼저 이해하고 자연스럽게 관심을 이어갈 수 있습니다.

사용자 니즈 현재 웹페이지 반영 방식
캐릭터 정보를
빠르게 확인하고 싶다 캐릭터 이미지와 소개 영역으로
정보 탐색 시간 단축
게임 분위기를
미리 경험하고 싶다 LP 히어로 비주얼과
스틸컷 이미지로 분위기 전달
주요 내용을
쉽게 파악하고 싶다 소개·캐릭터·스틸컷·다운로드로
정보 흐름을 단순화
다운로드 위치를
쉽게 찾고 싶다 다운로드 CTA로
실제 설치 행동 유도

감성적 스토리와 서브컬처 문법에 익숙하고,
음악 기반 콘텐츠에 관심이 높은 사용자층

Adoption Point

실제 활용 근거

운영 가능성

PC에서는 대형 비주얼과 정보 비교를,
모바일에서는 세로 스크롤 기반 구조로 실제 배포에 대응합니다.

현재 확보 에셋 활용

GitHub의 feat/landing-page 브랜치에 포함된
실제 웹사이트 이미지 에셋을 활용합니다.

이미 확보된 캐릭터·스틸컷·히어로 이미지를 사용하므로,
별도 콘셉트 설명 없이도 게임 분위기를 즉시 전달할 수 있습니다.

확보된 비주얼 리소스

  • 캐릭터 이미지 6종
  • LP 히어로 이미지
  • 노을 배경 및 스틸컷 이미지

웹페이지 구현 범위

  • UI/UX 구조 및 사용자 흐름 설계
  • 필름 스트립, 사선 그래픽, 섹션 레이아웃
  • HTML, CSS, JavaScript 반응형 퍼블리싱

Expected Effect

기대 효과

본 제안은 현재 완성된 웹페이지를 실제 게임 홍보 사이트로 사용하여,
사용자가 다운로드 전 게임의 세계관과 캐릭터 매력을 먼저 경험하도록 만드는 것을 목표로 합니다.

세계관 전달 캐릭터 인지도 향상 사용자 몰입도 향상 다운로드 전환율 증가 브랜드 아이덴티티 구축
